## 二、质量与安全基线

- 无新增第三方依赖；密钥/账号走环境变量（后台仅 adminUser 单账号，密码 bcrypt 哈希，登录锁定/审计沿用阶段 1）
- 会话安全：Redis session Cookie（HttpOnly）+ pysid_present 伴随标记；改密强制销毁会话；40100 统一跳登录
- 上传安全：全部媒体经后台 /admin/upload/image|video 入库接口（类型白名单 + 大小预校验，服务端过滤沿用阶段 1）
- 富文本：wangEditor 管理员受信输入，录入端校验 + 后台展示 v-html 仅限该受信来源
- 双语：后台界面文案 zh-cn 本地化 + 业务字段双语联动（英文留空自动翻译，人工值不被机器翻译覆盖——整表单保存语义）
- 危险操作（批量、删除）一律 confirmDanger 二次确认；删除一律逻辑删除（类目空删除物理清理死数据关联）
