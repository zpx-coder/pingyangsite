# ADR-0002 本地 MySQL 镜像版本（5.6.51 替代 5.6.16）

- 状态：已确认（2026-09-29，任务 0.3 执行中实测）
- 依据：开发计划方案 v2.2 §5.1、§10.1；ADR-0001 第 1 条

## 背景

生产数据库为负责人指定的 MySQL 5.6.16，本地基础设施按方案须与生产同版本。
任务 0.3 执行时实测：Docker Hub 官方 `library/mysql` **不存在 `5.6.16` 标签**
（`docker pull` 报 not found；`docker manifest inspect` 亦不可得）。

## 决策

本地开发与测试使用 **`mysql:5.6.51`** —— MySQL 5.6 系列最终版（2021-01，
即 5.6 EOL 前最后一个发布，含全系安全补丁）：

- 同一大系列（5.6），§5.1「MySQL 5.6.16 适配约定」全部成立：无原生 JSON
  列（TEXT 存储）、显式 utf8mb4、DATETIME(3)、不用 5.7+/8.0 独有特性；
- 生产仍按负责人指定用 5.6.16，兼容约定与连接串写法不变；
- 备选方案（自建 5.6.16 镜像 / 第三方镜像源）因构建成本与来源不可审计
  均不采用。

## 结果（Consequences）

1. 本地与生产存在 5.6.16 → 5.6.51 的 patch 差异；两版本同属 5.6 系列，
   差异仅为安全修复与 bug fix，不影响 schema 与查询行为。
2. 若后续需要「与生产逐字节同版本」的本地验证，可再评估自建镜像方案。
