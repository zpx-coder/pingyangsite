## 1. 需求概述

### 1.1 需求背景

平阳外贸对接会已由第三方平台（一彩宝 iyicaibao.com）提供现成专题页面
（HTTP 200 可访问，2026-10-08 实测）。官网无需重复建设专题页与报名系统，
仅在顶部导航提供「外贸对接会」入口，点击直达该外部页面。

### 1.2 需求目标

官网顶部导航「特色产业」菜单右侧新增「外贸对接会」菜单选项，点击后跳转到
外部链接 https://www.iyicaibao.com/ycb_static/pingyang/index.html。

### 1.3 本期范围（In Scope / Out of Scope）

**In Scope**

- 官网顶部导航新增菜单项「外贸对接会」（中/英双语文案）；
- 菜单项点击跳转外部链接（新标签页打开，见决策项 D-2）；
- E2E 新增菜单项与外链属性断言。

**Out of Scope（v1.1 已确认内容随 v1.2 取消）**

- 外贸对接会站内专题页（/matchmaking）；
- 报名弹窗与报名提交链路、防刷机制；
- 后台「对接会报名管理」模块（列表、统计、状态、导出）；
- 报名数据表 matchmaking_registrations 与相关公开/管理接口；
- 页面内容管理新增 matchmaking_page 配置；
- 对接会页面 TDK / hreflang / sitemap 增项（无新增站内页面）。

## 2. 官网功能需求

### 2.1 顶部导航新增「外贸对接会」（外链）

| 项 | 说明 |
| --- | --- |
| 位置 | 「特色产业」菜单右侧、「新闻动态」左侧；导航顺序变为：首页 / 平阳介绍 / 特色产业 / **外贸对接会** / 新闻动态 / 联系我们 |
| 交互 | 普通可点击菜单项（非悬停下拉式），点击后**新标签页**打开外链（建议，见 D-2） |
| 外链地址 | `https://www.iyicaibao.com/ycb_static/pingyang/index.html`（中/英态同一链接，见 D-3） |
| 高亮 | 外链点击即离开官网，不参与站内当前页高亮规则 |
| 双语 | zh「外贸对接会」；en「Trade Matchmaking」（沿用 v1.1 D-6 已确认英文命名） |

**实现要点**

- 全站公共导航（[site-header.tsx](../../frontend/site/src/components/site-header.tsx)）items 数组新增
  external 类型项，渲染为原生 `<a>`，携带 `target="_blank"` 与
  `rel="noopener noreferrer"`（防反向篡改与引荐泄漏）；
- 外链 URL 提取为命名常量（禁止魔法字符串，编码规范 §4.2）；
- i18n 字典 nav 新增 `matchmaking` 键（zh/en）；
- 新标签页打开不阻塞官网浏览上下文，无站内路由/中间件/SEO 变更。

## 4. 验收标准

- [ ] 导航「外贸对接会」位于「特色产业」右侧、顺序正确，zh「外贸对接会」/
      en「Trade Matchmaking」文案随语言切换；
- [ ] 点击后新标签页打开 `https://www.iyicaibao.com/ycb_static/pingyang/index.html`，
      携带 rel="noopener noreferrer"；
- [ ] 既有导航行为无回归（特色产业悬停下拉、站内高亮、语言切换）；
- [ ] E2E 全量通过（原 15 场景 + 新增外链场景，总场景数 ≤ 20）。
