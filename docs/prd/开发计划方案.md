## 1. 项目概述与范围

### 1.1 定位

平阳产业带官网独立站：面向全球采购商，展示平阳特色产业集群、产品与企业，
承接海外询盘；运营人员经管理后台独立维护内容与处理询盘。文案定位为产业带
独立站，**不得出现政府/政务类表述**（项目既定决策）。

### 1.2 范围（以 PRD §3 为准，摘要）

**官网**：首页、平阳介绍、产业类目页、产品详情页（含询盘表单）、企业详情页、
新闻列表页、新闻详情页、联系我们、404 页、全局中英切换。

**后台**：登录鉴权、产品管理、企业管理、类目管理、内容管理（新闻 + 页面内容
5 个配置项）、询盘管理、账号管理。

**不做**：移动端独立版本、前台用户体系、在线交易、多账号权限、AI 文案生成、
站内 IM、全局搜索、工作台统计页、隐私政策页。

## 5. 数据模型与 API 规范

### 5.1 数据库（PRD §8.2 + 补充）

8 张表：categories、companies、company_categories、products、news、inquiries、
page_contents、admin_users（与 PRD §8.2 一致；不建审计表——负责人确认，操作留痕
由应用日志承担，见 §9）。

索引：products(category_id, status, sort)、inquiries(created_at, status)、
news(publish_time, status, is_top)、page_contents(key UNIQUE)。Prisma migration
管理；种子脚本初始化超级管理员与 page_contents 5 个配置项默认值。

**MySQL 5.6.16 适配约定**（负责人指定版本，全链路遵守）：

- 无原生 JSON 类型（5.7.8 才引入）：images、honor_images、machine_fields、
  config 等 JSON 字段一律以 TEXT 列存储，应用层统一序列化/反序列化（封装于
  packages/shared，禁止散落手工 JSON.parse）；
- 字符集显式 utf8mb4（5.6 默认非 utf8mb4，建库脚本与连接串均须指定）；
- Prisma DateTime → DATETIME(3)，5.6.16 支持；不使用 5.7+/8.0 独有特性
  （JSON 列、窗口函数、CTE），为后续升级 5.7/8.0 预留兼容。

### 5.2 API 规范

- 前缀 `/api/v1/public/*`（官网读 + 询盘提交）、`/api/v1/admin/*`（会话鉴权）；
- 统一响应 `{ code, message, data }`；分页 `{ page, pageSize, total, list }`
  （后台 20/页、官网类目页 12/页）；
- 会话：HttpOnly + Secure + SameSite=Lax Cookie，8 小时过期；连续失败 5 次锁定
  15 分钟（PRD §7.0）；接口层独立鉴权，不依赖前端路由守卫；
- 询盘提交：图形验证码（Redis 存 5 分钟）+ 同 IP 1 分钟 ≤3 次 + 每日总量上限 +
  幂等防重（PRD §6.4/§9.2）。

### 5.3 双语与自动翻译流程

保存（仅填中文）→ 检测英文字段缺失 → 调用翻译（超时/失败不阻塞保存）→ 生成
英文并记录「机器翻译」字段标记（machine_fields，TEXT 列存 JSON 序列化）→ 人工编辑后清除对应
标记；官网渲染优先当前语言字段，为空回退另一语言；提供「一键翻译」重译入口。

## 7. AI 执行规范

1. **执行模式**：按第 6 章顺序逐任务执行；每任务完成即自验并提交；每阶段结束
   向负责人提交该阶段验收报告，经确认后进入下一阶段。
2. **变更确认**：架构级、破坏性、跨 5 文件以上重构、依赖变更、配置变更、删除
   3 个以上文件，先向负责人说明并获同意（CLAUDE.md 第一章）；执行中发现需求
   歧义，回问负责人，不自行猜测。
3. **提交纪律**：一个逻辑变更一个 commit（Conventional Commits，中文 subject）；
   每任务完成立即提交；功能分支开发、main 仅 PR 合入；每日推送远程。
4. **验证纪律**：任务未通过其验收标准即未完成；验证命令见附录 B；禁止未验证
   提交。
5. **记录纪律**：Todolist.md 按时间顺序追加执行记录（CLAUDE.md 第十一章）；
   架构决策写入 docs/adr/。
6. **安全底线**：密钥只进环境变量（.env 不入库）；后端独立校验全部入参；SQL
   参数化；上传白名单校验；日志脱敏（电话/邮箱）；定期依赖漏洞扫描。
7. **内容规范**：页面文案与演示数据遵守「平阳产业带独立站」定位，不得出现
   政府/政务表述；演示数据标注虚构；AI 生成内容经负责人审查后方可上线。
8. **素材规范**：官网自有内容图片由 AI 按设计阶段方式网络搜索抓取并本地化
   存储；产品/企业/新闻图片由运营录入时自带。
9. **回退保障**：实验性改动在独立分支进行；每次破坏性操作前确认回退方案。
