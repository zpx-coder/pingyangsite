## 1. 项目概述

### 1.1 项目背景

平阳县是温州市重要制造业基地，拥有宠物用品、塑编包装、印刷包装、礼品文具、
汽摩配、机械装备等多个特色产业集群。为提升平阳特色产业的全球影响力，需要一个面向全球推广的产业带官网：

- 对外：宣传平阳、展示特色产业类目、类目下的优势产品与优质企业，承接海外采购
  询盘，服务于全球招商与贸易对接；
- 对内：运营人员通过管理后台维护产品、企业、新闻、类目与页面内容，并集中处理
  官网提交的询盘。

### 1.2 项目目标

1. 建成中/英双语的 PC 端官网，支持全球访问与双语一键切换；
2. 建成 PC 端管理后台，首期一个超级管理员账号，覆盖产品、企业、类目、内容、
   询盘、账号六大管理域；
3. 部署于阿里云，绑定域名全网可访问（上线前完成 ICP 备案）。

### 1.3 成功指标（建议）

- 官网上线后 3 个月内，日均 UV ≥ 500；
- 官网询盘提交可用性 100%（表单提交 → 后台可见 ≤ 5 分钟）；
- 后台运营人员可独立完成产品/企业/新闻/页面内容的全流程维护，无需开发介入；
- 双语切换覆盖率 100%（所有面向用户的界面文案与业务内容均有中英版本或回退
  方案）。

## 3. 需求范围

### 3.1 本期范围（In Scope）

**PC 端官网（无需登录）**

1. 首页：顶栏菜单、宣传图（轮播）、特色产业类目展示、关于平阳、新闻热点、联系我们；
2. 平阳介绍：纯图文 + 视频内容介绍平阳；
3. 产业类目页：展示该类目下的产品列表与企业列表；
4. 产品详情页：图文展示产品信息，提供发询盘功能（填写询盘内容与联系方式，
   提交至管理后台）；
5. 企业详情页：展示企业信息及其关联产品列表；
6. 新闻列表页、新闻详情页；
7. 联系我们页、404 页；
8. 全局中/英双语切换。

**PC 端管理后台（首期 1 个超级管理员）**

1. 登录 / 鉴权 / 退出；
2. 产品管理：增删改查、关联企业（选填）、批量操作；
3. 企业管理：增删改查；
4. 类目管理：增删改查、排序、上下架；
5. 内容管理：新闻热点增删改查 + 页面内容配置（首页宣传图轮播、平阳介绍、联系我们等）；
6. 询盘管理：统计汇总、列表查看、状态处理、导出；
7. 账号管理：修改绑定的登录手机号与密码（原密码验证）。

### 3.2 非本期范围（Out of Scope）

- 移动端独立版本 / 小程序 / APP（本期仅 PC 端，移动端浏览体验做基本适配，
  见 9.4）；
- 前台用户注册、登录、会员体系；
- 在线交易、支付、订单、物流；
- 多账号、角色与权限体系（首期仅超级管理员）；
- AI 自动生成产品文案（确认不涉及）；
- 站内询盘回复 / 在线聊天（IM）；
- 全局搜索（类目页列表内的筛选见 6.3，全局站内搜索列入后续规划）；
- 后台独立「工作台」统计页（询盘统计汇总由询盘管理页顶部统计卡片承载，已确认）；
- 官网隐私政策页（本期不建设，列入后续规划，已确认）。

### 4.2 URL 与语言规范

- 官网语言采用路径前缀方案：`/{lang}/...`，`lang ∈ {zh-CN, en}`；
  访问根路径 `/` 时按浏览器语言 302 跳转，默认 `zh-CN`；
- 后台统一 `/admin/...` 前缀，不分语言（后台仅中文界面）；
- 页面 TDK（标题 / 描述 / 关键词）随语言切换，见 9.3 SEO。

## 5. 全局规范

### 5.1 官网全局框架

**顶栏导航（所有公开页一致）**

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| Logo | 平阳产业带品牌标识 + 站点名 | 点击回首页 |
| 菜单 | 首页 / 平阳介绍 / 特色产业 / 新闻动态 / 联系我们 | 当前页高亮；「特色产业」悬停下拉展示全部上架类目，点击进入对应类目页 |
| 语言切换 | 中文 / English 切换按钮 | 切换后当前页以另一语言重新渲染，语言选择持久化（LocalStorage + Cookie） |

**页脚（所有公开页一致）**

导航链接、友情提示语、联系方式摘要、ICP 备案号（后台「页面内容-页脚信息」可
配置，上线前必须填真实备案号）、版权信息。

**404 页**：提示语 + 返回首页按钮，双语。

### 5.2 双语与自动翻译方案

1. 后台业务内容（产品、企业、类目、新闻、页面内容）的所有文案字段均维护
   **中文 + 英文两份**；
2. 编辑保存时，若仅填写了一种语言，系统调用**机器翻译 API**（建议阿里云机器
   翻译，与部署环境同生态）自动生成另一语言版本，并打上「机器翻译」标记；
3. 后台编辑页提供「一键翻译」按钮，可随时对单个字段或整条内容重新翻译；
4. 翻译结果可人工修改，保存后标记自动清除；
5. 翻译失败不阻塞保存：保存成功后在后台提示"翻译失败，请稍后重试"，内容以已
   填语言为准；
6. 官网渲染规则：优先取当前语言的对应字段；该语言字段为空时回退另一语言
   （不回退为空页面）；
7. 界面静态文案（导航、按钮、表单标签、提示语）由前端 i18n 资源文件维护，随
   语言切换。

### 5.3 富文本与媒体规范

- 产品详情、新闻正文、平阳介绍等使用富文本编辑器，支持：标题、段落、加粗、
  列表、图片、视频插入、链接；禁止直接粘贴外部样式；
- 图片：统一存 OSS，格式 jpg/png/webp，单张 ≤ 5MB，上传后生成缩略图（列表卡
  片用），详情用原图，CDN 分发；
- 视频：mp4，单文件 ≤ 2GB（超大视频建议运营侧先转码），OSS 存储 + CDN 播放，
  播放器带封面图、播放/暂停、进度条、音量、全屏；
- 建议尺寸：产品主图 ≥ 800×800（1:1），新闻封面 16:9 ≥ 1280×720，企业 Logo
  ≥ 200×200（1:1），宣传图（轮播）16:9 建议 ≥ 1920×800。

## 6. 官网功能需求

> 每个页面的高保真原型见《原型.html》，对应路由见各节「原型锚点」。

### 6.1 首页（#/home）

**页面定位**：平阳产业带的第一门户，一屏内传达"平阳是谁、有什么产业"，并引导
访客进入类目、新闻与询盘转化路径。

| 区块 | 内容 | 数据来源 | 交互 |
| --- | --- | --- | --- |
| 宣传图轮播区 | 全宽轮播图（1–5 张，自动轮播 + 手动切换），每张叠加主标语、副标语、行动按钮 | 后台页面内容-首页宣传图（轮播） | 自动轮播（默认 5 秒/张）；左右箭头/指示点切换；按钮跳转平阳介绍/特色产业区 |
| 特色产业类目区 | 全部上架类目卡片（图标、名称、简介），最多 8 个 | 类目管理 | 点击卡片进入类目页 |
| 关于平阳区 | 左图文右文案 + 「了解更多」按钮 | 后台页面内容-首页关于平阳 | 按钮进入 /about |
| 新闻热点区 | 最新 4 条新闻（封面、标题、日期、摘要） | 新闻管理（已发布，按发布时间倒序） | 点击进入新闻详情；「更多新闻」进入 /news |
| 联系我们区 | 电话、邮箱、地址、工作时间 + 「查看完整联系方式」 | 后台页面内容-联系我们 | 按钮进入 /contact |

**关键规则**

- 类目区仅展示「上架」状态类目，按排序值升序，最多展示 8 个；超出 8 个的
  类目仍可通过顶部「特色产业」下拉导航访问；
- 新闻区仅展示「已发布」新闻；置顶新闻优先展示；
- 轮播自动播放（默认 5 秒/张，后台可配间隔），鼠标悬停暂停；支持左右箭头
  与指示点手动切换。

### 6.2 平阳介绍页（#/about）

**页面定位**：用图文 + 视频完整讲述平阳的区位、产业带概况与发展成果。

| 模块 | 内容 | 数据来源 |
| --- | --- | --- |
| 页面横幅 | 页面标题 + 横幅图 | 后台页面内容-平阳介绍 |
| 视频模块 | 介绍视频（封面 + 播放器） | 后台页面内容-平阳介绍 |
| 图文内容区 | 富文本正文（可含图片），多段落分节 | 后台页面内容-平阳介绍 |

**关键规则**：正文由后台富文本配置，中英文分别维护（自动翻译辅助）；页内锚点
导航可选（正文分节超过 4 节时提供）。

### 6.3 产业类目页（#/category）

**页面定位**：类目聚合页——访客从首页类目卡片进入，在同一页浏览该类目下的全部
产品与全部企业。

| 模块 | 内容 | 交互 |
| --- | --- | --- |
| 面包屑 | 首页 > 特色产业 > {类目名} | 逐级可点 |
| 类目头图区 | 类目名（双语）、类目简介、产品/企业数量 | — |
| 标签页 | 「产品列表」/「企业列表」切换 | 默认产品列表 |
| 产品列表 | 产品卡片（主图、名称、所属企业、参考价格/MOQ 若有） | 点击进入产品详情；分页（每页 12 个） |
| 企业列表 | 企业卡片（Logo、名称、简介摘要、产品数） | 点击进入企业详情；分页（每页 12 个） |

**关键规则**

- 仅展示「上架」类目；该类目下「已发布」产品与「上架」企业；
- 产品按排序值升序、更新时间倒序兜底；企业同规则；
- 类目下无产品时展示空状态文案；无企业时企业标签页展示空状态。

### 6.4 产品详情页（#/product）

**页面定位**：产品展示与询盘转化页，是官网的核心转化入口。

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 面包屑 | 首页 > {类目} > {产品名} | 类目可点回类目页 |
| 图集区 | 主图大图 + 缩略图列表（主图 + 图集） | 点击缩略图切换大图，可放大查看 |
| 产品信息区 | 产品名（双语跟随语言）、所属类目、关联企业（若有，可点进企业详情；产品可不关联企业）、简介、参考价格（若有）、MOQ（若有） | — |
| 询盘入口 | 「发送询盘」按钮；产品已关联企业时同排展示「联系企业」按钮 | 点击滚动至页面下方询盘表单并聚焦 |
| 产品详情区 | 富文本图文详情 | 后台配置，双语跟随 |
| 该企业其他产品 | 关联企业下的其他已发布产品（除当前产品）卡片行；仅产品已关联企业时展示 | 点击进入对应产品详情 |
| 询盘表单 | 见下方字段表 | 提交成功后弹窗确认，不入库的内容不回显 |

**询盘表单字段**

| 字段 | 必填 | 校验规则 |
| --- | --- | --- |
| 姓名 | 是 | 2–50 字符 |
| 公司名称 | 否 | ≤ 100 字符 |
| 国家/地区 | 是 | 下拉选择（常用国家置顶 + 全部国家列表） |
| 邮箱 | 是 | 邮箱格式 |
| 电话/WhatsApp | 是 | 6–20 位数字（含 + 号、空格、-） |
| 询盘内容 | 是 | 10–2000 字符，预填模板"我对贵司的 {产品名} 感兴趣，请提供报价与 MOQ。"可修改 |
| 图形验证码 | 是 | 不区分大小写；验证失败刷新 |

**关键规则**

- 提交需通过验证码校验与频率限制（同 IP 1 分钟内 ≤ 3 次提交）；
- 提交成功后展示成功弹窗（"询盘已发送，我们将在 1–2 个工作日内与您联系"），
  可关闭/继续浏览；
- 后台按提交时间落库，记录来源语言、产品关联与企业关联（企业取产品关联
  企业；产品未关联企业时企业字段为空）；
- 产品被下架/删除后，详情页 404；已有询盘数据不受影响。

### 6.5 企业详情页（#/company）

**页面定位**：展示企业实力与资质，并聚合其全部产品供访客继续浏览。

| 模块 | 内容 | 说明 |
| --- | --- | --- |
| 面包屑 | 首页 > {类目} > {企业名} | — |
| 企业信息区 | Logo、企业名（双语）、所属类目（多选，逐个展示为标签）、基本信息（成立年份、规模、地址、联系人、电话、邮箱、官网） | 后台配置 |
| 企业简介区 | 富文本图文简介 | 后台配置 |
| 荣誉资质区 | 证书/荣誉图片墙（可选） | 无配置则不展示该模块 |

## 8. 数据模型

### 8.1 实体关系

```
Category 1 ──── N Product
Category M ──── N Company（经 company_categories 关联表，企业类目多选）
Company  1 ──── N Product（Product.company_id 可空：产品可不关联企业）
Product  1 ──── N Inquiry（Company 冗余在 Inquiry 中，可空）
AdminUser（单例）
PageContent（key 唯一）
News（独立）
```

### 8.2 表结构（建议）

```sql
-- 类目
categories(id, name_zh, name_en, icon_url, intro_zh, intro_en,
           sort, status, created_at, updated_at)

-- 企业
companies(id, name_zh, name_en, logo_url, cover_url, founded_year,
          scale, address, contact_name, phone, email, website,
          intro_zh, intro_en, honor_images(text), sort, status,
          created_at, updated_at)

-- 企业-类目关联（多对多：企业可归属多个类目）
company_categories(company_id, category_id)

-- 产品（company_id 可空：产品可不关联企业）
products(id, category_id, company_id, name_zh, name_en, main_image,
         images(text), intro_zh, intro_en, detail_zh, detail_en,
         price_ref, moq, sort, status, created_at, updated_at)
-- status: 0 草稿 / 1 已发布 / 2 已下架

-- 新闻
news(id, title_zh, title_en, cover_url, summary_zh, summary_en,
     content_zh, content_en, publish_time, is_top, status,
     created_at, updated_at)

inquiries(id, product_id, company_id, product_name_snapshot,

          email, phone, content, lang, status, ip, created_at)

-- 页面内容
page_contents(key, config(text), updated_at)

-- 管理员
admin_users(id, phone, password_hash, created_at, updated_at)
```

> （5.7.8 才引入），json 字段一律以 text 列存储、应用层序列化；字符集 utf8mb4。

## 9. 非功能需求

### 9.1 性能

- 官网首屏 LCP ≤ 2.5s（3G 网络下 ≤ 4s）；图片走 OSS + CDN，列表图懒加载；
- 官网视频采用点击加载策略，页面加载时不请求视频文件（先加载封面图）；
  首页轮播图首屏仅加载第一张，其余懒加载；
- 后台列表接口 P95 ≤ 500ms；数据库查询必须走索引；
- 询盘提交接口响应 ≤ 3s，防重复提交（前端禁用按钮 + 后端幂等校验）。

### 9.2 安全

- 全站 HTTPS（TLS 1.2+）；后台登录密码加盐哈希存储；
- 用户输入一律服务端二次校验；SQL 参数化；上传文件校验类型、大小并做恶意文
  件过滤；
- 询盘表单：图形验证码 + IP 频率限制 + 每日总量上限（防垃圾询盘）；
- 后台关键操作留痕：登录、增删改、导出、账号变更写入应用日志并脱敏（不建
  独立审计表，2026-09-28 负责人确认）；
- 敏感信息（电话、邮箱）在后台完整展示但日志中脱敏；
- 依赖漏洞定期扫描，中高危 1 个迭代内修复。

### 9.3 SEO

- 官网必须可被搜索引擎收录：建议采用 SSR / 预渲染方案（禁止纯前端渲染）；
- 每页独立 TDK；双语页面配置 hreflang；生成 sitemap.xml 与 robots.txt；
- URL 静态化（类目/产品/企业/新闻详情均可用 ID 或 slug）；
- 图片 alt、视频 poster 必须填写。

### 9.4 兼容性

- 浏览器：Chrome / Edge / Safari / Firefox 最新两个大版本；
- 分辨率：≥ 1366px 完整体验（设计基准 1920px，内容容器 1200px）；
- 移动端：本期不做独立移动端版本，但官网页面需做基本响应式适配（≥ 768px
  可用），供移动浏览器应急浏览（建议项）。

### 9.5 合规

- **上线前置**：完成工信部 ICP 备案与公安联网备案，备案号展示于页脚（境外访问
  走 CDN 不受影响，备案针对境内分发）；
- 询盘涉及个人信息收集：隐私政策页本期不建设（已确认），列入后续规划，上线
  前建议评估补充合规文案；
- 不实现任何规避贸易管制或法律限制的功能。

### 9.6 数据与运维

- 数据库每日自动备份（保留 30 天），关键变更前手动备份；
- 官网与后台独立部署进程、共用数据库；监控告警（可用性、磁盘、证书到期）；
- 访问统计（建议）：境内接入百度统计、境外接入 Google Analytics，双语站点
  分别埋点。
