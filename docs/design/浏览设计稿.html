设计说明（v2.0 · 依据「平阳站参考」视觉规范重做）
  • 配色：阳光金（#D9A93E / #E8BE4C / 浅金 #F6E7C8）+ 山海黛蓝青（#336065 / #28484C / #1F3A3D）+ 暖白底（#FFFFFF / 暖白 #F7F4EC / 暖灰 #E4E1DC），点缀红（#C13134）、茶棕价格（#A9713D）与橄榄色产业集群走马灯带（#C7B798）。对标参考图的「白底 + 金色主强调 + 黛蓝青大色块 + 暖色带」结构：顶栏浅金、主体暖白、联系带与页脚黛蓝青。标题采用宋体系字体增强庄重感。
  • Logo：采用官方「平阳 logo」图片（设计稿/平阳logo.jpg，白底方形）。官网头部等白底位置直接展示；页脚、后台登录页与后台侧栏等深色背景处以白色圆角底衬承载，保证辨识度与规范感。
  • 动效清单：Hero 轮播 Ken Burns 缓慢推镜 + 文案逐级入场 + 标题金色流光；页面滚动渐入（IntersectionObserver）；数据带数字滚动增长；类目/新闻卡片悬停抬升、图片缩放、金色描边生长；按钮光扫；产业集群走马灯；定位点呼吸跳动；返回顶部进度环。交互稿 ui.html 可直接体验。
  • 图片：官网自有内容图片沿用网络搜索抓取方式（负责人已定，不考虑授权与预算），产品/企业/新闻图片由运营录入时自带。本轮已将首页主视觉与"关于平阳"配图换为金色主题（金色落日海岸、晨雾山间茶园），呼应参考图金色调性。
  • 中英文：本稿以中文版呈现设计规范，英文版沿用同一框架（字体、版式、间距一致），具体以原型双语逻辑为准。
  • 已确认（2026-09-28 负责人确认）：① 新配色（阳光金 + 山海黛蓝 + 暖白）；② 官方 Logo 展示方式（白底直接展示 / 深色背景白色底衬）；③ 动效强度；④ 后台沿用同风格。图片选材方向已定：沿用网络搜索抓取。
